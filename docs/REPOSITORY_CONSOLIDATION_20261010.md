## 当面の独立開発方針（利用者指定：2026-10-10）
ModuForgeとFileWorkbench-Nextは独立した開発・試験・版管理・配布として進める。
ModuForgeの整理・モジュール/API整備はNextへの移行や同期を前提条件にしない。NextもModuForgeの完成を待たず、そのリポジトリ内の現行コードで独立して進められる。
現段階では自動同期、共通コードへの置換、依存パッケージ化、タグ/Organizer等の取り込み、両プロジェクトの版連動は行わない。
分離元の来歴は保持するが、来歴は現在の実行時依存関係を意味しない。
将来、ModuForgeの部品が整備された段階で、Nextへの組み込みを別作業として扱い、選定した部品/API版を固定して統合試験を行う。
現在の優先作業はModuForge内の一本化と受入確認。Next・旧FileWorkbenchの整理は別作業として扱い、ModuForgeとの接続をその完了条件にしない。

## 従来版の整理
旧FileWorkbenchに残るNext PR #1/#2と作業ブランチは、Nextのソース・修正・試験記録への移行照合後に閉じる。mainへ機械的にマージしない。
プリセット/入力候補、タグ、整理、退避/世代管理、重複整理、リネームUndo、HTML/Excel出力、設定移行を比較する。旧版の機能がNextにすべてあるとは扱わない。
旧版のコミット、タグ、配布物、NOTICE、試験記録を保持。対応範囲が決まるまではアーカイブ化しない。非公開設定を維持する。
