# FileWorkbench Next 3.3 RC 開発派生版

## 元版

`FileWorkbench_Next_3.3_RC_Interaction_Recovery_Preview.zip`

## 修正目的

Windowsでシンボリックリンク作成権限が無い場合に、リンク作成時の `WinError 1314` でビルド時テスト全体が失敗する状態を避けます。

## 変更点

- 上書き禁止の検査をシンボリックリンク検査から分離しました。
- リンク作成を試し、OS権限などの理由で作成できない場合は、そのリンク検査だけを `unittest` のスキップとして記録します。
- リンク作成が許可されている環境では、元の安全性検査を実行します。
- アプリ本体のリンク・ジャンクションへの安全処理は変更していません。
- UTF-16 BOMを判定してから、BOMなしテキストをUTF-8、CP932の順で読み、Windowsの既定文字コードによる日本語テスト失敗を防ぎます。

## 確認状況

- 変更したPythonファイルの構文確認: 実施
- CP932・UTF-8・UTF-16 BOMの読込確認: 実施
- 添付されたWindows試験画面では47件中、文字コードの失敗1件と詳細未確認のエラー1件を確認。見えていた文字コード問題は修正済み。
- 自動試験: この実行環境に `PySide6` が無いため実行できず
- Windows実機ビルド・EXE確認: 未実施

画面に表示されていないもう1件のエラーは、`build.log` 全体がないため原因未確定です。最終確認にはWindowsで再度 `scripts\\run_tests.bat` を実行し、まだエラーがあれば `build.log` を確認してください。

Windowsでの確認は、開発環境をセットアップ後、プロジェクト直下で `scripts\\run_tests.bat` を実行してください。合格後に `scripts\\build_release.bat` でEXEを作成します。

このパッケージは FileWorkbench Next 3.3 RCから作成した**開発中の派生版**です。Windows確認前の最終リリースとしては扱わないでください。
